# Folder asset

Taruh gambar QRIS di sini dengan nama persis: **qris.png**

Path yang dipakai kode: `asset/qris.png` (dipanggil dari `index.html` / `js/app.js`
pada bagian modal Top Up).

Kalau file belum ada, aplikasi akan menampilkan placeholder
"Gambar QRIS belum ditemukan" secara otomatis (lihat elemen
`#topup-qris-missing` di index.html), jadi tidak akan error — cukup taruh
file-nya di sini kapan pun siap.
