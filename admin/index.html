Repositori GitHub situs

Cara membuat token
  1. Buka GitHub, lalu Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Pada Repository access, pilih Only select repositories dan pilih repo situs ini saja.
  3. Pada Repository permissions, atur Contents menjadi Read and write.
  4. Buat token, salin, lalu tempel di kolom di atas.
